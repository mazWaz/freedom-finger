Jadwal

Jadwal utama berlaku untuk semua karyawan, kecuali yang dipilihkan jadwal lain di menu Karyawan. Lembur dinyalakan per hari: di hari kerja dihitung setelah jam pulang, di hari libur seluruh jam kerja dihitung lembur. Maks. jam = lembur paling lama hari itu; kosong berarti tanpa batas. Bebas = datang dan pulang kapan saja: hadir bila scan, tanpa terlambat, pulang cepat, atau lembur. Bulatan warna di samping nama jadwal = warna jadwal di Hari ini.

Jenis

Hari kerja dengan catatan ini tidak dihitung alpa, walau ada scan.

  1. Nyalakan mesin dan cari

    Mesin dan server Freedom Finger harus tersambung ke jaringan kantor yang sama.

  2. Isi menu mesin

    Di mesin buka Menu → Jaringan, isi persis seperti ini, lalu simpan:

    Minta admin jaringan mereservasi IP server di router. Bila IP-nya berubah, mesin tidak bisa mengirim absen ke sana.

  3. Tunggu mesin terhubung

  4. Mulai pakai

Dihitung di Rekap seperti scan biasa, dan tampil bertanda "manual" di Riwayat. Log di mesin tidak diubah.
